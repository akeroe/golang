## Консольная игра "Угадай число" на Go

Это простая консольная игра, написанная на языке программирования Go (Golang). Компьютер загадывает случайное число, а игрок должен угадать его за ограниченное количество попыток.

## Функционал проекта
- Выбор уровня сложности (Легкий, Средний, Сложный).
- Цветной вывод текста в консоли для лучшего игрового опыта.
- **Сохранение результатов:** история всех сыгранных партий (дата, исход игры и количество оставшихся попыток) автоматически записывается в файл `results.json`.
- Код структурирован и разбит на отдельные логические функции.

## Как запустить проект

Для запуска игры на вашем компьютере должен быть установлен [Go](https://go.dev).

1. Склонируйте репозиторий:
   
   git clone https://github.com/akeroe/golang.git
   
2. Перейдите в папку с проектом:
   
   cd firstgofolder
   
3. Запустите игру:
   
   go run main.go
   

## Пример игрового процесса


Выберите уровень сложности:
1 - Легкий (1-10, 5 попыток)
2 - Средний (1-100, 10 попыток)
3 - Сложный (1-1000, 15 попыток)
Ваш выбор: 1

Введите ваше число: 5
Загаданное число больше! У вас осталось 4 попыток.
Введите ваше число: 8
